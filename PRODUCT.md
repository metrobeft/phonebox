# Product

<!-- impeccable:product-schema 1 -->

## Platform

android

## Product Purpose

O PhoneBox transforma o HP 7.1 1201 em um painel de mesa para acompanhar e controlar o PC. O agente Windows fornece a telemetria, o estado de mídia e as integrações pela rede local.

## Operating Context

O APK nativo é a interface principal. O painel web legado oferece acesso pelo navegador do tablet. O editor de configurações roda no PC e incorpora uma prévia da versão web.

## Capabilities and Constraints

- Android 4.2.2 (API 17), tela de 1024 × 600, 1 GB de RAM, uso em paisagem e retrato.
- Java e Android Views para o APK. HTML, CSS compatível com o navegador antigo e JavaScript ES5 para o painel web.
- Controles de mídia e volume, atalhos, processos, telemetria, IA, Discord e relógio/clima.
- A ordem das abas, o tema e as opções de apresentação podem vir do agente.
